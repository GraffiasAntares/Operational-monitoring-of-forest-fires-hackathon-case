# Web-интерфейс «Лесной дозор»

React + TypeScript интерфейс для API мониторинга лесных пожаров. Карта показывает
оперативные очаги и пожарные события, а карточка выбранного события запускает
слои гари, тяжести dNBR и оценки ущерба лесу.

## Запуск

В одном терминале запустите API из корня репозитория:

```powershell
python -m uvicorn backend.app.main:app --reload
```

В другом:

```powershell
cd frontend
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (по умолчанию `http://localhost:5173`).
В development запросы `/api` автоматически проксируются на `127.0.0.1:8000`.
Для развёрнутого API задайте `VITE_API_BASE_URL` в `.env` на основе
`.env.example`.

Поле «Архивная дата» на панели карты необязательно. Оставьте его пустым для
near-real-time очагов или укажите дату, чтобы получить архивные FIRMS-данные за
выбранное число дней.

## Проверка

```powershell
npm run build
```
